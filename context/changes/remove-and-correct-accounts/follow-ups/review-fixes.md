# Review fixes: remove-and-correct-accounts

Follow-ups queued during triage of `reviews/impl-review.md`.

- [ ] **F1, plan wording.** plan.md:65 orders the ban "the deactivation update … then `banned_at`". The code now claims `banned_at` first, with a conditional write, then pauses, so two concurrent bans cannot both go on and Reactivate cannot clear a fresh pause before the ban is recorded. Add an addendum to the plan's Critical Implementation Details recording the new order and why.
- [ ] **F2, plan wording.** The plan says "The role picker is unchanged" (Phase 3 §3, State sequencing). It is now disabled on Banned rows, and `changeUserRole` refuses any role write while `banned_at` is set. Removing the role would strand the ban, and granting one to a row with no role would insert it unpaused. Record this in the addendum, beside Reactivate's refusal.
- [ ] **F3, plan wording.** Phase 2 §3 and criterion 2.2 list "409 `last_admin` for ban and delete of the last active admin" under the integration suite. That proof now lives in `supabase/functions/admin-users/last-admin.test.ts` (Deno), because the integration lane cannot make a sole admin while other files run. Note the move in the addendum.
- [ ] **F6, plan wording.** plan.md:65 says "Delete cannot use that lock across `deleteUser`", and that two admins deleting each other can both pass. Delete now pauses the target through the session first (`pauseTarget`, shared with ban), so the guard's lock serialises it, and the pause is cleared again if the record or the delete fails. Record this in the addendum.
- [ ] **F7, accepted risk.** Record in the addendum: `change_email` (with `email_confirm: true`, no link) works on another admin's row, so one admin, or a stolen admin session, can move a colleague admin's address and then reset their password. Accepted because admins are trusted with accounts, the `email_changed` row names the actor, and an admin can already create another admin: it adds impersonation, not access. Not yet checked: whether hosted Auth sends an "email changed" notice to the old address.
